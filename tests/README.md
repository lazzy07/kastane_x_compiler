# KastaneX Test Suite

This tests project contains testing functionality for all the domains in [Sabre Benchmark Problems](https://github.com/sgware/sabre-benchmarks/tree/main/problems), and also, testing for specific functionalities of this compiler.

All the tests are written using [Google Tests](https://github.com/google/googletest).

## Where to find `Unit test` source code

You can find the source code for unit tests under `tests/src`. When you program new functionality for the compiler, make sure to write tests under that directory.
